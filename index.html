APP DE VERIFICAÇÃO / OAUTH 2.0 YouTube Data API v3

Verificação de membros

Somente membros ativos.

Sistema de autenticação OAuth que verifica assinaturas pagas do YouTube em tempo real e concede acesso a conteúdo exclusivo — sem senhas, sem dados sensíveis.

Para criadores

Conceda acesso a benefícios exclusivos apenas para membros pagos do seu canal. Verificação automática, segura e via API oficial do Google.

Como funciona →
OAuth 2.0 Autenticação Google
1h Sincronização automática

§ 01
Escopo OAuth

Autorização restrita

Apenas o escopo necessário. Nada mais.

O aplicativo solicita um único escopo restrito do Google para verificar membros ativos do canal. Usuários finais nunca recebem este escopo — apenas o criador do canal o utiliza, uma única vez.

→ 01

Escopo do criador

Usado pelo dono do canal para sincronizar a lista de membros ativos via YouTube Data API v3.

youtube.channel-memberships.creator
→ 02

Escopo do usuário

Usado no login do membro para obter o ID público do canal. Acesso somente leitura, sem permissões sensíveis.

youtube.readonly
→ 03

Verificação

O sistema compara o channelId do usuário autenticado com a lista de membros sincronizada. Se houver correspondência, o acesso é concedido automaticamente.

§ 02
Fluxo completo

Método

Do OAuth ao acesso em cinco passos.

O criador autentica uma vez. O sistema sincroniza membros automaticamente. O usuário faz login e recebe acesso — ou não — baseado no status real da assinatura no YouTube.

→ 01 Auth do criador

O dono do canal faz OAuth uma única vez com o escopo memberships.creator.

→ 02 Sync de membros

O sistema consulta a API do YouTube a cada hora e mantém a lista de membros ativos atualizada localmente.

→ 03 Login do usuário

O membro faz login com Google usando o escopo padrão youtube.readonly.

→ 04 Comparação

O ID do canal do usuário é comparado com a lista de membros ativos sincronizada.

→ 05 Acesso concedido

Se for membro ativo, o acesso ao conteúdo exclusivo é liberado. Caso contrário, acesso negado.

§ 03
Privacidade

Transparência total

O que coletamos — e o que não coletamos.

Utilizamos apenas o mínimo necessário para verificar sua assinatura. Nenhum dado sensível é armazenado em texto puro. Nenhum dado financeiro passa pelo sistema.

→ Coletamos

  • 01 ID público do canal do YouTube (channelId)
  • 02 Nome público do canal (displayName)
  • 03 Nível da assinatura (membershipLevelName)

→ Não coletamos

  • ✕ Senhas ou credenciais de acesso
  • ✕ Dados financeiros ou cartão de crédito
  • ✕ Informações pessoais sensíveis
  • ✕ Histórico de navegação ou atividade
