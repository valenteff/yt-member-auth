Channel Members Auth
Verificação de membros de canais do YouTube

Aplicativo de autenticação OAuth para creators verificarem membros ativos

📋 Finalidade do aplicativo

Este aplicativo permite que criadores de conteúdo do YouTube verifiquem se um usuário é um membro ativo e pago do seu canal, usando a YouTube Data API v3. O sistema é usado para conceder ou negar acesso a conteúdo exclusivo e benefícios baseados no status de assinatura.

🔐 Escopo OAuth restrito utilizado

Este aplicativo solicita o seguinte escopo restrito do Google:

https://www.googleapis.com/auth/youtube.channel-memberships.creator

Como é usado: O criador do canal faz autenticação uma única vez. O sistema então chama o endpoint /youtube/v3/members para listar os membros ativos do canal. Apenas o criador (admin) usa este escopo.

Usuários finais autenticam com o escopo padrão youtube.readonly — não recebem o escopo restrito.

ℹ Sobre

O Channel Members Auth é um sistema que sincroniza a lista de membros ativos de um canal do YouTube através da API oficial do Google, permitindo verificar assinaturas para conceder acesso a benefícios exclusivos.

Ao fazer login com sua conta Google, verificamos se você é um membro ativo do canal. Nenhum dado pessoal sensível é armazenado — apenas seu ID público do canal do YouTube.

📊 Dados coletados

Utilizamos apenas o mínimo necessário para verificar sua assinatura:

• ID público do canal do YouTube (channelId)

• Nome público do canal (displayName)

• Nível da assinatura (membershipLevelName)

Não coletamos: senhas, dados financeiros, informações de cartão de crédito ou qualquer dado sensível.

⚙ Como funciona

1. O criador do canal faz OAuth uma única vez com o escopo memberships.creator

2. O sistema sincroniza a lista de membros via API a cada hora

3. O usuário faz login com Google (escopo youtube.readonly)

4. O sistema compara o ID do canal do usuário com a lista de membros

5. Se for membro, o acesso é concedido automaticamente
